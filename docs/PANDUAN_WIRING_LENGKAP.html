1. Overview Sistem

Sistem HydroIoT menggunakan konfigurasi power sebagai berikut:

  • PSU Utama: 12V DC
  • Step-Down: LM2596 (12V → 5V untuk relay & ESP32)
  • ESP32: Mikrokontroler utama
  • Relay Module: 3-channel, 5V, active LOW dengan optocoupler
  • Beban: Pompa air 12V, Pompa nutrisi 12V, Kipas 12V

4. Penjelasan VCC vs JD-VCC

4.1 Apa itu VCC dan JD-VCC?

💡 Info: Pada modul relay 5V dengan optocoupler, terdapat 2 jalur daya terpisah:
  • VCC: Daya untuk sirkuit optocoupler dan driver transistor (logic side)
  • JD-VCC: Daya untuk koil relay (coil side)
Pin Fungsi Tegangan Arus Catatan
VCC Daya logic/optocoupler 3.3V - 5V ~10-20mA Untuk LED optocoupler & transistor driver
JD-VCC Daya koil relay 5V ~70-150mA per relay Untuk medan magnet koil relay
GND (logic) Ground sisi logic 0V - Harus sama dengan ESP32 GND
GND (coil) Ground sisi koil 0V - Harus sama dengan GND logic

4.2 Jumper VCC-JD-VCC: Pasang atau Lepas?

🚨 KRITIS: Jumper VCC-JD-VCC menentukan apakah sirkuit relay terisolasi atau tidak!

6. Wiring Ground (GND Bersama)

6.1 Mengapa Harus GND Bersama?

💡 Prinsip: Semua ground harus terhubung ke satu titik (common ground) agar referensi tegangan sama untuk semua komponen.

6.2 Diagram Common Ground

═══════════════════════════════════════════════════════════════════ COMMON GROUND (GND BERSAMA) ═══════════════════════════════════════════════════════════════════ PSU 12V (-) │ │ ┌─────────┴─────────┐ │ │ │ TITIK GND │ │ UTAMA │ │ │ └─────────┬─────────┘ │ ┌───────────────────┼───────────────────┐ │ │ │ │ │ │ ┌────▼────┐ ┌────▼────┐ ┌────▼────┐ │ LM2596 │ │ ESP32 │ │ RELAY │ │ GND │ │ GND │ │ GND │ └─────────┘ └─────────┘ └─────────┘ │ │ │ │ │ │ ┌────▼────┐ ┌────▼────┐ ┌────▼────┐ │ LOAD │ │ LOAD │ │ LOAD │ │ (-) │ │ (-) │ │ (-) │ │ Pompa │ │ Kipas │ │ Sensor │ └─────────┘ └─────────┘ └─────────┘ CATATAN: - Semua GND terhubung ke PSU 12V (-) - LM2596 GND = ESP32 GND = Relay GND = PSU GND - JANGAN buat GND terpisah (bisa menyebabkan noise)

6.3 Tips Wiring GND

⚠️ Penting:
  • Gunakan kabel yang cukup tebal untuk GND (AWG 18 atau lebih tebal)
  • Hindari GND loop (lingkaran ground yang tidak perlu)
  • Pastikan semua koneksi GND kencang dan tidak longgar
  • Gunakan terminal block atau solder untuk koneksi yang reliable

8. Masalah Umum & Solusi

Masalah Penyebab Solusi
ESP32 Reset Random Noise dari relay mengganggu power ESP32
  • Lepas jumper VCC-JD-VCC
  • Pasang kapasitor 100µF di VIN ESP32
  • Gunakan power supply terpisah untuk relay
Relay Tidak Bisa Switch Arus tidak cukup atau koneksi longgar
  • Cek koneksi JD-VCC ke 5V
  • Pastikan GND terhubung dengan baik
  • Uk tegangan di JD-VCC (harus 5V)
Relay Selalu ON Sinyal control salah atau pull-up/internal
  • Cek apakah active LOW atau HIGH
  • Pastikan GPIO diatur ke OUTPUT
  • Set GPIO HIGH untuk OFF (active LOW)
LoRa Tidak Stabil Noise EMI dari kabel relay
  • Jauhkan antena LoRa dari kabel relay
  • Gunakan kabel shielded untuk LoRa
  • Pasang kapasitor 100nF di VCC LoRa
Sensor TDS Noise Ground loop atau noise power
  • Pastikan semua GND bersama
  • Pasang kapasitor 10µF di VCC sensor
  • Gunakan kabel twisted pair untuk analog

9. Best Practices & Tips

9.1 Noise Reduction

═══════════════════════════════════════════════════════════════════ NOISE REDUCTION TECHNIQUES ═══════════════════════════════════════════════════════════════════ 1. KAPASITOR DECOUPLING ───────────────────────── - 100µF electrolytic di VIN ESP32 - 100nF ceramic di VCC relay - 10µF di VCC sensor analog 2. FLYBACK DIODE ───────────────────────── - 1N4007 paralel dengan koil relay - Anode ke NO/NC, Cathode ke COM - Melindungi dari voltage spike 3. SEPARASI DAYA ───────────────────────── - Relay coil: LM2596 5V - Relay logic: ESP32 3.3V - Sensor: ESP32 3.3V/5V 4. LAYOUT KABEL ───────────────────────── - Pisahkan kabel power dari sinyal - Minimal 5cm jarak antara kabel relay dan LoRa - Gunakan kabel twisted pair untuk sinyal analog

9.2 Tips Wiring

✅ Best Practices:
  • Kabel: Gunakan kabel berwarna berbeda (merah=VCC, hitam=GND, lain=sinyal)
  • Koneksi: Gunakan terminal block atau solder, hindari breadboard untuk produksi
  • Label: Beri label pada setiap kabel dan terminal
  • Dokumentasi: Foto semua wiring sebelum ditutup
  • Testing: Test satu per satu komponen sebelum digabung
  • Safety: Selalu matikan PSU saat modifikasi wiring

9.3 Kapasitor yang Direkomendasikan

Lokasi Tipe Nilai Fungsi
ESP32 VIN Electrolytic 100µF / 16V Filter noise low frequency
ESP32 VIN Ceramic 100nF Filter noise high frequency
Relay JD-VCC Ceramic 100nF Filter switching noise
Sensor VCC Electrolytic 10µF / 10V Stabilisasi tegangan sensor
LoRa VCC Ceramic 100nF Filter noise untuk komunikasi

## 1.2 Diagram Koneksi Voltage Divider HC-SR04

```
HC-SR04 ECHO (5V)
        │
       [R1: 1kΩ]
        │
        ├──────────────► GPIO33 ESP32 (3.3V max)
        │
       [R2: 2kΩ]
        │
       GND

Vout = 5V × 2000/(1000+2000) = 3.33V ✓
```

## 3.2 ESP32 ↔ DHT22

```
┌─────────────────┐              ┌─────────────────────┐
│      ESP32      │              │        DHT22         │
│                 │              │  (tampak depan)      │
│ 3.3V         ───┼─────────────►│ Pin 1 (VCC)          │
│ GPIO4        ◄──┼──────────────│ Pin 2 (DATA)         │
│ -               │    (skip)    │ Pin 3 (NC)           │
│ GND          ───┼─────────────►│ Pin 4 (GND)          │
└─────────────────┘              └─────────────────────┘

Catatan: Internal pull-up ESP32 aktif di firmware
         Tidak perlu resistor pull-up eksternal
```

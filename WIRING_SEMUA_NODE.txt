--------------------------------------------------------------------------------
  KOMPONEN YANG DIBUTUHKAN (per node)
--------------------------------------------------------------------------------
  - ESP32 DevKit V1 (38-pin atau 30-pin)
  - LoRa E32-433T20D (modul UART, bukan SPI)
  - Sensor DHT22 (suhu + kelembapan)
  - Sensor HC-SR04 (ultrasonik, ketinggian air)
  - Sensor TDS Meter (analog, 3.3V atau 5V)
  - Modul Relay 3-channel (active LOW)
  - Resistor 1k ohm x1  ]  voltage divider
  - Resistor 2k ohm x1  ]  untuk ECHO HC-SR04
  - Kabel jumper
  - Power supply 5V 2A (minimal)

      HC-SR04 ECHO (5V)
            │

           [2k ohm]
            │
           GND

  Rumus: V_GPIO = 5V x 2k/(1k+2k) = 3.33V  ← aman untuk ESP32 (maks 3.6V)

  - Kalibrasi pakai program test_tds.ino terlebih dahulu

  - Active LOW: kirim LOW = relay ON, kirim HIGH = relay OFF

  - Untuk pompa air 220V: Fasa → COM → NO → Pompa → Netral
  - Relay di SISI KANAN agar tidak numpuk dengan LoRa+DHT22 (SISI KIRI)

  LAYOUT FISIK ESP32 DevKit V1 (30-pin, USB di atas):

  USB
   |
   |  [PIN KIRI]           [PIN KANAN]
   |  3.3V                 VIN (5V)
   |  GND                  GND
   |  GPIO 15  (bebas)     GPIO 13   (bebas)
   |  GPIO  2  (bebas)     GPIO 12   !!! JANGAN DIPAKAI !!!
   |  GPIO  4  → DHT22    GPIO 14   (bebas)
   |  GPIO 16  → LoRa RX  GPIO 27   ← Relay3 (Kipas)
   |  GPIO 17  → LoRa TX  GPIO 26   ← Relay2 (Pompa Nutrisi)
   |  GPIO  5  (bebas)     GPIO 25   ← Relay1 (Pompa Air)
   |  GPIO 18  → LoRa AUX GPIO 33   ← ECHO HC-SR04
   |  GPIO 19  (bebas)     GPIO 32   ← TRIG HC-SR04
   |  GPIO 21  → LoRa M0  GPIO 35   ← TDS Node 3 saja
   |  GPIO  3  (RX0)       GPIO 34   (bebas, input only)
   |  GPIO  1  (TX0)       GPIO 39   ← TDS Node 2 saja
   |  GPIO 22  → LoRa M1  GPIO 36   (bebas, input only)
   |  GPIO 23  (bebas)     EN

  KIRI  = LoRa E32 (5 pin) + DHT22 (1 pin) → PADAT, jangan tambah lagi
  KANAN = Sensor (32,33,39/35) + Relay (25,26,27) → rapi, masih ada sisa


================================================================================
  GPIO YANG TIDAK BOLEH DIPAKAI + CATATAN STRAPPING (ESP32)
================================================================================

  JANGAN DIPAKAI:
  GPIO 6, 7, 8, 9, 10, 11  → Terhubung ke flash internal, pasti error
  GPIO 34, 35, 36, 39       → Input only, tidak bisa output
                               (dipakai TDS: input only = sudah benar)
  GPIO 1, 3                 → UART0 Serial Monitor, hindari untuk output

  STRAPPING PIN (perlu perhatian tapi AMAN untuk relay):
  ┌──────────┬──────────────────────────────┬────────────────────────────────┐
  │  GPIO    │  Efek jika LOW saat boot     │  Status di sistem ini          │
  ├──────────┼──────────────────────────────┼────────────────────────────────┤
  │  GPIO  0 │  Masuk mode Download/Flash   │  Dipakai reset WiFi gateway    │
  │  GPIO  2 │  Harus LOW untuk download    │  TIDAK dipakai → aman          │
  │  GPIO  5 │  SDIO alternate mode         │  Relay3 Node3, init HIGH=OFF ✓ │
  │  GPIO 12 │  Flash voltage 1.8V (rusak!) │  TIDAK dipakai → aman          │
  │  GPIO 15 │  Suppress boot log UART0     │  Relay2 Node2, init HIGH=OFF ✓ │
  └──────────┴──────────────────────────────┴────────────────────────────────┘

  KENAPA GPIO 5 DAN 15 AMAN UNTUK RELAY?
  - Relay modul active-LOW dengan optocoupler internal pull-UP
  - Saat boot, pin ESP32 belum jadi OUTPUT → modul relay menarik pin ke HIGH
  - HIGH = relay OFF = kondisi yang BENAR untuk strapping pin 5 dan 15
  - Setelah boot, firmware langsung set pinMode OUTPUT + digitalWrite HIGH
  - Tidak ada risiko relay nyala tiba-tiba saat boot ✓


================================================================================
  CATATAN PENTING KELISTRIKAN
================================================================================

  1. POWER SUPPLY
     - Gunakan adaptor 5V 2A untuk setiap ESP32 + relay
     - Jangan pakai port USB laptop sebagai sumber utama jika relay aktif
     - Relay butuh arus lebih besar saat switching

  2. GROUNDING
     - Semua GND harus tersambung (ESP32 GND = Relay GND = Sensor GND)
     - GND bersama mencegah noise pada pembacaan ADC (TDS)

  3. SENSOR TDS
     - Gunakan 3.3V untuk VCC modul TDS
     - Output AOUT otomatis ≤ 3.3V → LANGSUNG ke GPIO ESP32, tanpa voltage divider
     - ADC ESP32 tidak linear, sudah dikompensasi di firmware (formula cubic)
     - Kalibrasi WAJIB dilakukan sebelum deploy menggunakan test_tds.ino
     - Kalibrasi tersimpan di flash NVS, tidak hilang saat ganti program

  4. RELAY
     - Pasang flyback diode (1N4007) paralel dengan koil relay
       jika tidak menggunakan modul relay (hanya bare relay)
     - Modul relay biasanya sudah ada optocoupler dan diode

  5. LORA E32
     - WAJIB ada antena sebelum dinyalakan (tanpa antena bisa rusak)
     - Jarak antar antena minimal 1-2 meter saat pengujian indoor
     - Channel 0x17 = 433.875 MHz

  6. HC-SR04
     - WAJIB voltage divider di pin ECHO
     - Tanpa voltage divider, ESP32 bisa rusak (pin toleransi maks 3.6V)
     - Sensornya menggunakan 5V, output ECHOnya juga 5V


================================================================================
  URUTAN PENGERJAAN YANG DISARANKAN
================================================================================

  TAHAP 1 - Kalibrasi TDS (pakai test_tds.ino)
  ├── Flash test_tds.ino ke ESP32 Node 2
  ├── Buka Serial Monitor 115200 baud
  ├── Celupkan probe TDS ke air 200 ppm → ketik: cal1 200
  ├── Celupkan probe TDS ke air 500 ppm → ketik: cal2 500
  ├── Celupkan probe TDS ke air 1000 ppm→ ketik: cal3 1000
  ├── Ketik: show → verifikasi semua titik tersimpan
  └── Ulangi untuk ESP32 Node 3 (GPIO TDS berbeda: 35)

  TAHAP 2 - Upload Program Utama
  ├── Flash sensor_client_node2.ino ke ESP32 Node 2
  │     → Kalibrasi terbaca otomatis dari NVS (tidak perlu kalibrasi ulang)
  ├── Flash sensor_client_node3.ino ke ESP32 Node 3
  └── Flash gateway.ino ke ESP32 Gateway

  TAHAP 3 - Konfigurasi WiFi Gateway
  ├── Nyalakan Gateway ESP32
  ├── Jika pertama kali → HP connect ke WiFi "HydroIoT-Setup"
  ├── Buka browser → 192.168.4.1
  ├── Isi SSID + Password WiFi rumah/kampus
  └── (Opsional) Isi Firebase Host & Auth Key jika perlu ganti

  TAHAP 4 - Verifikasi
  ├── Buka Serial Monitor Gateway → cek data masuk dari Node
  ├── Buka Firebase Console → cek /sensors/node2 dan /sensors/node3
  └── Buka index.html → data sensor tampil di web dashboard

  UNTUK GANTI WiFi (tanpa reflash):
  └── Tahan tombol BOOT (GPIO 0) saat ESP32 Gateway dinyalakan
      → Otomatis buka portal 192.168.4.1
